GitHub 授權設定

Token 只在目前頁面記憶體中使用，重新載入後需再輸入。它只會傳送至 api.github.com，不會加入分享連結或儲存庫。

  1. 準備私人資料儲存庫；已建立的毋須重建。新增儲存庫時請勾選 README。
  2. 到 GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens 建立 Token。
  3. Repository access 選 Only select repositories，只選私人資料儲存庫。Contents 選 Read and write；唯讀使用者選 Read-only。

找回已搬移的項目：按「建立 / 加入項目 → 讀取此儲存庫的項目」。其他舊項目可用 JSON 備份匯入；舊版分享連結不能直接加入。
